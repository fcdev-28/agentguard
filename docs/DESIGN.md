# Dirección de Diseño

## Sensación del producto

AgentGuard debe sentirse como software operacional serio: preciso, calmado, rápido y confiable.

Referencias de calidad:

- Linear para densidad, navegación y jerarquía.
- Stripe para claridad alrededor de riesgo, dinero y permisos.
- Raycast para velocidad e interacción tipo comando.
- Vercel para pulido contenido y credibilidad técnica.

## Principios visuales

- Tipografía fuerte antes que decoración.
- Jerarquía clara antes que color.
- Densidad suficiente para operadores, nunca saturación.
- Nada de páginas CRUD genéricas.
- Nada de tarjetas dentro de tarjetas.
- Nada de gradientes morados.
- Nada con aspecto Bootstrap.
- El movimiento debe aclarar cambios de estado, no entretener.

El detalle de tokens, componentes y patrones vive en [Sistema visual](DESIGN_SYSTEM.md).

## Prioridades de interfaz

Las superficies principales deben hacer evidente:

- Identidad del agente.
- Riesgo actual.
- Aprobaciones pendientes.
- Acciones recientes.
- Resultado de política.
- Responsable humano.
- Rastro de auditoría.

## Pantallas sugeridas

- Dashboard de control.
- Agentes.
- Cola de revisión.
- Detalle de acción.
- Políticas.
- Registro de auditoría.
- Ajustes.

## Notas de motion

- Los botones deben tener feedback de pulsación sutil.
- Paneles laterales y popovers deben sentirse rápidos, por debajo de 250 ms.
- Interacciones intensivas de teclado deben evitar animación decorativa.
- Las alternativas de movimiento reducido deben existir desde el inicio.

## Tono de copy

Claro, directo y operacional.

Bueno:

- Aprobar reembolso
- Escalar acción
- Bloquear acceso a herramienta
- Revisar coincidencia de política

Evitar:

- Supercargar agentes
- Desbloquear flujos autónomos
- Potenciar a tu equipo
- Gobierno de nueva generación
