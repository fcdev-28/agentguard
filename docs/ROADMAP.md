# Roadmap del MVP

## Sprint 0: Base

- Confirmar posicionamiento de producto.
- Elegir stack.
- Definir modelo de datos.
- Crear el primer sistema de diseño.
- Preparar datos semilla.

## Sprint 1: Estructura estática del producto

- Layout de la aplicación.
- Navegación.
- Vista general del dashboard.
- Lista de agentes.
- Estados vacíos y de carga.

## Sprint 2: Revisión de acciones

- Cola de aprobación.
- Detalle de acción en panel lateral o página.
- Aprobar, rechazar y pedir cambios.
- Etiquetas de riesgo y explicaciones de política.

## Sprint 3: Capa de políticas

- Permisos por herramienta.
- Reglas de umbral.
- Reglas de aprobación humana.
- Evaluación simulada de políticas.

## Sprint 4: Auditoría e investigación

- Registro de auditoría.
- Vista de línea temporal.
- Filtros.
- Detalles de evento.
- Estructura preparada para exportación.

## Sprint 5: Pulido de producto

- Comportamiento responsive.
- Revisión de accesibilidad.
- Revisión de motion.
- Estados de error.
- Refinamiento de copy.
- Datos de demo realistas.

## Objetivo de la primera demo

Un usuario debe poder abrir AgentGuard, ver agentes activos, revisar acciones de riesgo, aprobarlas o rechazarlas, inspeccionar por qué se activó una política y entender el rastro de auditoría.
